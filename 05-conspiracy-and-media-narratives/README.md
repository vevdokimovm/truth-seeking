## Not empirical claims (handled separately)

- **Ex-rabbi converts to Christianity** (Mr. Discloser). This is a **personal faith testimony**, not an empirical claim to test or "debunk". It's noted here only because it shares the source screenshot batch — it does not belong in the evaluation table above.
- **Lana Rhoades asks to remove old videos** (@rapseatv). A news item about a person's request, not a claim about the world.

## Why the calendar one is worth keeping

It's the cleanest example in the repo of the most common trick: **wrap a real, verifiable fact in an unsupported conspiratorial frame.** The etymology checks out; the "hidden truth being suppressed" does not. Separating the true kernel from the false shell is exactly the skill the whole `00-method` toolkit is for.
