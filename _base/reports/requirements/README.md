# requirements/ — спецификации требований (SRS)

Здесь лежат заполненные **спецификации требований** (SRS — Software Requirements Specification) для
code-реп. Тип «SRS» в диспетчере `../../00-infrastructure/19-reporting-system.md`.

В knowledge-репе применяется редко (там нет разрабатываемого софта с требованиями).

Рабочие шаблоны и гайды (порт из FINPILOT, v1.6.0):

| Файл | Что это |
|---|---|
| `requirements-guide.md` | Как писать требования: EARS-формулировки + реестр — рабочий минимум |
| `srs-guide.md` | Гайд по артефакту SRS: структура, как заполнять, критерии качества |
| `requirements-sop.md` | SOP работы с требованиями (боевой процесс FINPILOT — как образец) |
| `requirements-sop-universal.md` | Универсальная версия SOP — база для адаптации под свою репу |

> Заполненные SRS наследующей code-репы кладутся сюда же, рядом с гайдами.
