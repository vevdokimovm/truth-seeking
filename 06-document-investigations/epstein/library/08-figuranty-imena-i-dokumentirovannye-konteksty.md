# 08 — Фигуранты: имена и документированные контексты

> Поимённая карта по состоянию на 08.07.2026. Правило чтения, без которого этот файл превращается в клевету: **упоминание в файлах ≠ вина**. Категория №4 EFTA намеренно широка (все «названные или упомянутые»), поэтому в корпус попали и свидетели, и персонал, и случайные люди — эпизод, когда Бланш «разоблачил» шесть зачернённых имён, а четверо оказались случайными людьми из старой опознавательной подборки FBI, это доказал на практике. По сводке CNBC, **никто** из публичных лиц, затронутых волной 2026 г., не обвинён в преступлениях Эпштейна. Формат каждой позиции: имя → что документировано (тип артефакта) → ответ/статус. Имена жертв здесь не собираются (закон и этика); исключение — публичные фигуры, сами вышедшие в публичность.

## 9. Как самому вытащить ВСЕ имена из корпуса (машинный конвейер)

«Все имена» руками из 3,5 млн страниц не достаются — только конвейером по локальной копии (файл 07):
1. Скачать корпус, прогнать OCR (07, §1–3).
2. Очистить артефакты: письма конвертировались в PDF с мусором кодировки (лишние «=» и переносы) — нормализовать до NER.
3. NER: spaCy `en_core_web_trf` (PERSON) по всем текстам; для русскоязычных вставок — natasha.
4. Нормализация сущностей: регистр, инициалы, OCR-варианты написания, титулы; кластеризация тёзок по контексту.
5. Частотная таблица: {имя, число упоминаний, датасеты/дела, роль по контексту}; ручная верификация топа по первичным документам.
6. Контроль: сверка с внешним индексом EpsteinExposed (независимая база: ~2,15 млн документов, ~1500 персон каталогизировано к 03.2026) — как ориентир, не как истина.
Предупреждения: OCR-шум даёт ложные «имена»; сырой список публиковать нельзя (клевета + жертвы) — публикуемый вывод только после ручной верификации контекста каждой позиции.

## 10. Неотредактированный список должностных лиц

EFTA обязывает передать судебным комитетам Палаты и Сената **неотредактированный список всех госдолжностных лиц и политически значимых лиц (PEP)**, фигурирующих в файлах, — комитетам, не публике. Исполнение этой обязанности — часть общего спора о соблюдении закона (файл 05).
