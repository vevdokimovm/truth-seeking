# 07 — Практикум исследователя: скачивание, обработка, этика

> Как превратить 3,5 млн страниц в рабочий локальный корпус и не навредить ни себе, ни жертвам. Все шаги — легальны: материалы официально опубликованы правительством США для публичного использования.

---

## 1. Скачивание

**Принципы:** только официальные источники (justice.gov, oversight.house.gov и их прямые хранилища); никакой «зеркальной» экзотики без проверки; уважай инфраструктуру (троттлинг).

**Схема массового скачивания датасетов:**
1. Собери манифест: обойди страницы пагинации `data-set-N-files?page=K` и выпарси прямые ссылки `…/epstein/files/DataSet%20N/EFTA########.pdf` (страницы — обычный Drupal-HTML, парсится requests + BeautifulSoup).
2. Качай по манифесту очередью с ограничением скорости и повторами: `aria2c -i manifest.txt -j 4 --retry-wait=10 --max-tries=5` или `wget --input-file=manifest.txt --wait=1 --random-wait --continue`.
3. Пропуски номеров в манифесте — фиксируй отдельным списком (это отозванные на редактуру документы, см. файл 03, §2.1): их стоит перепроверять при обновлениях.
4. House Oversight: папки Google Drive/Dropbox удобнее забирать целиком (Drive: «Скачать всё» → zip; либо rclone для больших объёмов).
5. Объёмы существенные (видео и изображения января 2026 — сотни гигабайт): планируй диск, качай выборочно по задаче.

## 2. Целостность и датировка снимков

- Сразу после скачивания: `sha256sum * > SHA256SUMS-YYYY-MM-DD.txt` по каждому датасету;
- Храни дату снимка: массив живой (документы отзывались, восстанавливались, редактуры менялись); два снимка одного файла с разными хэшами — сам по себе исследовательский факт;
- Манифесты и хэш-листы — в git (это текст); сами PDF/медиа — вне git (правило: бинарники в историю не тащим), локальный диск + внешний бэкап.

## 3. OCR и извлечение текста

- Значительная часть массива — сканы, факсы, рукописи; текстовый слой либо отсутствует, либо ненадёжен (портал сам предупреждает о ненадёжности поиска);
- Конвейер: `ocrmypdf --skip-text --optimize 1 in.pdf out.pdf` (не трогает уже текстовые PDF, добавляет слой к сканам); для пакетной обработки — очередь на Python с multiprocessing;
- Рукописи Tesseract берёт плохо — помечай такие файлы флагом «ручной просмотр»;
- Извлечение текста для индекса: `pdftotext` / PyMuPDF; таблицы (журналы, логи) — Camelot/табличные распознаватели с обязательной ручной сверкой.

## 4. Индексация и поиск по корпусу

- Быстрый старт без кода: `rga` (ripgrep-all) ищет прямо по PDF;
- Системный вариант: SQLite + FTS5 — таблица (bates_id, dataset, path, sha256, date_snapshot, text), полнотекстовый индекс; на Python собирается за вечер и переживает обновления корпуса;
- Метаданные заводи сразу: датасет, Bates-номер, контур происхождения (DOJ/Oversight/суд), дата снимка — без этого дифф-методика из файла 06 не работает;
- Дедупликация: точная — по sha256; смысловая (один документ в разных сканах/редактурах) — fuzzy-hash (ssdeep) или сравнение нормализованного текста; дубликаты не удаляй, а связывай — расхождения редактур между «дубликатами» информативны.

## 5. Верификация и рабочая гигиена выводов

- Подлинность: сходимость Bates-номеров, реквизитов дел, дат и подписей с судебными доккетами (файл 06, §2); tip-слой (04, §6) по умолчанию считается непроверенным;
- Цитирование: идентификатор документа (EFTA-Bates или дело+докет) + дата снимка + контур; скриншот без идентификатора — не источник;
- Формулировки: «в опубликованном массиве документ не обнаружен по такой-то методике» вместо «документ скрыли»; «имя зачернено» вместо домыслов о том, чьё оно;
- Помни презумпции: упоминание ≠ причастность; наличие в массиве ≠ подлинность; отсутствие в поиске ≠ отсутствие в массиве.

## 6. Этика и безопасность (обязательный блок)

1. **Жертвы — красная линия.** Не пытайся деанонимизировать зачернённые имена жертв и не распространяй случайно неотредактированные персональные данные (сайт сам признаёт, что такие утечки возможны). Обнаружил утечку — не публикуй, сообщи на **EFTA@usdoj.gov**.
2. **CSAM.** В официальном массиве его нет и быть не должно. Любые «полные версии без цензуры» из неофициальных источников — с высокой вероятностью либо фальшивка, либо незаконный контент; не скачивать, не хранить, не пересылать.
3. **Психологическая нагрузка.** Материалы содержат описания насилия (официальное предупреждение источника). Дозируй работу, не читай показания потерпевших без необходимости для конкретной исследовательской задачи.
4. **Юридическая аккуратность.** Публикуя выводы о живых людях, отделяй факт документа («в письме X от даты Y сказано Z») от оценок; помни про презумпцию невиновности и широту категории «упомянутые лица» в EFTA.
5. **Не корми фальшивки.** Tip-слой и вирусные «выжимки» из соцсетей — главный источник искажений; правило: нет идентификатора документа — нет репоста.

## 7. Мини-чеклист развёртывания локального корпуса

- [ ] Манифесты датасетов собраны, пропуски Bates зафиксированы отдельно.
- [ ] Скачивание с троттлингом, только официальные URL.
- [ ] SHA256-листы с датой снимка; бинарники вне git.
- [ ] OCR-слой добавлен; рукописи помечены для ручного разбора.
- [ ] Индекс (FTS) с метаданными: датасет, Bates, контур, дата снимка.
- [ ] Правила этики из §6 приняты как неотменяемые.
