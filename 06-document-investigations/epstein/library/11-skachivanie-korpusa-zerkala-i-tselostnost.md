# 11 — Скачивание корпуса: зеркала и целостность

> Прямой скрейп justice.gov мёртв: сайт за Akamai Bot Manager (отдаёт 403 скриптам), а массовые ZIP-скачивания DOJ убрал ~6 февраля 2026, заставив открывать по одному PDF. Рабочий путь — ZIP-архивы через community-зеркала, с проверкой по SHA256. Это не «копии от рандомов»: сходимость нескольких независимых источников по хэшам — более сильная модель доверия, чем один скрейп госсайта, который на ходу правит листинги.

## 2. Три источника (в порядке простоты)

1. **GeekenDev HTTP-зеркало** — `https://doj-files.geeken.dev/doj_zips/original_archives/DataSet%20N.zip`. Проще всего: HTTP + докачка через aria2, торрент-клиент не нужен. Минус — один сервер, может тормозить.
2. **Internet Archive** — `https://archive.org/download/data-set-1/DataSet%20N.zip` (DS8/10/12 — свои item'ы: `data-set-8`, `data-set-10`, `data-set-12_202601`). Третий слой сохранности, HTTP-докачка.
3. **Торрент-магниты** (`magnets.txt`) — самый надёжный для крупных датасетов (docsets 9/10/11), устойчив к троттлингу, качает из роя. Нужен qBittorrent/Transmission (`brew install qbittorrent`).

## 3. Как качать (готовый скрипт)

`epstein_download.sh` (кладётся рядом с `SHA256SUMS_datasets.txt`):

```bash
brew install aria2
./epstein_download.sh text      # датасеты 1-8 + 12 → папка zips/ (~14 ГБ)
./epstein_download.sh verify    # сверка скачанного с хэшами GeekenDev
# позже, если нужно медиа:
./epstein_download.sh media     # 9,10,11 (~287 ГБ) — лучше через торрент, см. magnets.txt
```

Скрипт качает с GeekenDev с докачкой (`-c`), 8 потоков; при провале датасета подсказывает fallback.

## 4. Критично: источники НЕ байт-идентичны

У части датасетов SHA256 разных источников **различаются** (см. `SHA256SUMS_datasets.txt`):
- DS3, DS7, DS10, DS12 — все три источника совпадают;
- DS2, DS4, DS5, DS6, DS8 — torrent = GeekenDev, но archive.org отличается;
- **DS1 — все три разные.**

Причина по индекс-репо: пометка «*updated torrent contains less redactions*» — т.е. по некоторым датасетам ходят версии **с меньшим числом зачернений**, не совпадающие с оригинальным DOJ-zip. Для truth-seeking это и есть интересная зона: сравнение «оригинал vs менее отредактированная версия» показывает, что именно DOJ закрывал. Практика: (1) фиксируй, из какого источника качал; (2) сверяй с хэшем **того же** источника; (3) для чистоты «что было официально» бери archive.org/GeekenDev-оригинал, для «что скрыли» — сравнивай с less-redacted торрентом отдельно, не смешивая.

## 5. Известные дыры (честно)

- **DS9 неполный у самого DOJ**: сервер обрывался на ~49 ГБ из 180. Лучшая реконструкция (@jeefiles, ~181,3 ГБ) добирает почти всё; но ~23 файла (диапазон EFTA00709804…EFTA01135708) и ~10,1 ГБ видео (EFTA00276494.ts, EFTA01244748.wmv, EFTA01244749.wmv), похоже, DOJ так и не выложил. Это дыра источника, не твоя.
- **DS10**: листинг на сайте со временем менялся (10 фев показывал меньше файлов, чем архив от 30 янв) — верифицируй по хэшу архива.
- **DS12**: минимум 3 PDF отсутствуют в zip (EFTA02731790/812/852) — лежат отдельными файлами на сайте.
- Internet Archive заявляет 1 366 140 заархивированных PDF — как независимый ориентир полноты.

## 6. После скачивания → в конвейер (файл 10)

```bash
cd zips
for z in DataSet_*.zip; do unzip -q "$z" -d "../corpus/${z%.zip}"; done
```

Дальше — ровно этапы 3–7 из файла 10: OCR фоном → `efta_index.py build` → FTS-поиск → NER-имена → батч-разбор со мной. Манифест-скрипт (`efta_manifest.py`) на justice.gov больше не нужен — структуру даёт сам распакованный архив (папки IMAGES/NATIVES + метаданные VOL000NN.DAT/.OPT внутри).
