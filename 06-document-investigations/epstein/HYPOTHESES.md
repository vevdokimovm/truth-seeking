## Как использовать этот чеклист

1. Для каждой строки — прогон по локальной копии корпуса (`corpus/DS0N/`) по search plan: точные фразы + OCR-варианты (мусорные «=», разрывы строк — см. `library/07`).

4. Не путать статус «упомянут» со статусом «виновен» — особенно для раздела H (публичные фигуры) и для co-conspirator/иммунитетных фигур раздела E/B.
