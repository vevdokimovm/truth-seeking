## 4. Конвейер одного батча

`tools/run_stage.sh A|B|C|D` → `tools/efta_to_md.py` (расширение `docs_to_md.py` лабы).

1. файлы читаются **прямо из zip на archive.org** (HTTP Range, `remotezip`) — исходник
   на диск не ложится вовсе, «удалить после обработки» выполняется автоматически.
   Замер: 102 стр. DS6 за 23 с — сеть не узкое место, узкое место OCR;
2. PDF: есть текстовый слой → `pdftotext` (лаба: `docs_to_md.py`, режим извлечения);
   нет → OCR tesseract, с сохранением средней уверенности OCR в паспорт;
   OCR не взял → чёрный блок >20 % страницы = **🔲 зачернено DOJ** (найдено глазами на
   EFTA00008599: 4 из 6 «отказов» оказались редактурами), иначе **🔴 отказ OCR**;
3. `.md` на документ: шапка — EFTA-номер, датасет, страниц, метод, уверенность OCR;
4. FTS-индекс SQLite по всем `.md` (для синтеза);
5. исходник удалён (разрешение владельца 25.09.2026; датасет публичный, адресуется по EFTA);
6. замер в `_base/07-media-to-text-lab/measurements.csv`, прогон — в `runs/`.
