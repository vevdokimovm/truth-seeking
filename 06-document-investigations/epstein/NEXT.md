## 4. Этап E — медиа

1 610 видео/аудио (DS2, DS8, DS10, DS11, DS9) → `video_to_note.py` лабы (whisper).

### Запуск (ночью, машина свободна)

```bash
cd ~/repos/truth-seeking/06-document-investigations/epstein
nohup bash tools/run_stage_e.sh >> ~/epstein/stageE.log 2>&1 &
```

`run_stage_e.sh` делает три вещи по порядку: **проверяет машину** (своп и load —
занята, откажется стартовать), **снимает A/B-замер VAD** на двух реальных файлах
с записью в `asr-timings.csv`, затем идёт по очереди. Флаги: `--no-bench` — без
замера, `--force` — мимо проверки машины.

🔴 **Замер стоит первым не для порядка.** Три дневные попытки померить сорвались:
Ollama и своп (6.4 ГБ из 7) роняли долю CPU у whisper с 342 % до 41 %, коэффициент
уходил за ×10. Замер обязан сниматься той же машиной и в тех же условиях, в которых
пойдёт очередь, иначе он не про неё (METHOD-SPEECH §7а).

Прогон **resumable**: файл с готовой нотой пропускается, прерывать можно в любой
момент. Проверить ход — `tail ~/epstein/stageE.log`, счётчики
`media N/M silent=S failed=F`. Только аудио или только видео —
`run_media.sh audio` / `run_media.sh video`.

### Конфигурация 30.09.2026 — почему она такая

🔴 **Метод — `_base/07-media-to-text-lab/METHOD-SPEECH.md`, замеры — `asr-timings.csv`.**
Первый прогон 29–30.09 шёл темпом **один файл за 80 минут** (7 нот за 10.5 часов):
очередь заканчивалась через 89 суток. Причина — модель гоняли по тишине.

| Что включено | Зачем |
|---|---|
| `--vad` + silero (`ggml-silero-v5.1.2.bin`) | энкодер работает только по речи; таймкоды пересчитываются к оригиналу |
| `--lang en` | `auto` тратит **лишний прогон энкодера** на определение языка |
| `--kind audio` первым проходом | 118 чистых аудиофайлов — самая плотная речь, часы вместо месяцев |
| предфильтр `silencedetect` | полностью немые файлы закрываются нотой-замером без запуска модели |

🟡 **Проверено и НЕ помогает** (`METHOD-SPEECH.md` §3): больше потоков, отключение
beam search, `-vn` у ffmpeg. Не тратить на них время повторно.

### Замер 30.09.2026 на свободной машине — числа, по которым считается срок

| Файл | | без VAD | с VAD |
|---|---|---:|---:|
| `EFTA00221046.m4a` (звонок, 3 мин) | время | 683 с · **×3.81** | 699 с · ×3.89 |
| | слов | 407 | 402 |
| `EFTA00033407.mp4` (CCTV, 5 мин) | время | 552 с · ×1.84 | 11 с · **×0.04** |
| | слов | 20 | **0** |

🔴 **Двадцать слов CCTV — галлюцинация.** Десять сегментов подряд «Thank you.»,
по одному на 30-секундное окно. `volumedetect`: `mean = max = -91.0 dB` —
цифровая тишина. VAD на порогах 0.5/0.3/0.2 не нашёл речи и был прав.
Проверка корпуса: **9 нот из 25** оказались такой галлюцинацией (119–121 одинаковый
сегмент) — удалены, пойдут заново. В конвейер добавлен детектор: ≥80 % совпадающих
сегментов → пометка в ноте и счётчик `suspect=` в прогрессе.

🟡 **На плотной речи VAD не ускоряет** (×0.98) и стоит 5 слов из 407 при 92.2 %
совпадения. Держим его ради страховки от галлюцинаций в паузах, не ради скорости.
