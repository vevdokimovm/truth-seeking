# 00 — Method: инструментарий исследователя

Переносимый набор инструментов — как вообще думать о любом утверждении, где искать источники, как читать исследования и как не дать статистике себя обмануть. Всё в тематических папках `02–06` — это применение того, что лежит здесь.

Читать по порядку — это мини-курс, от фундамента к конкретным техникам проверки.

## Содержание

| Файл | О чём |

| [`01-evaluation-framework.md`](01-evaluation-framework.md) | Единый чек-лист для разбора любого claim'а. Рабочая точка входа. |

| [`03-scientific-method-and-reasoning.md`](03-scientific-method-and-reasoning.md) | Научный метод, фальсифицируемость, причинность, бремя доказательства, байесовское мышление. |
